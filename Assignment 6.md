Basic Page of html?

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="My First Web Page - HTML & CSS course assignment">
    <title>My First Web Page</title>
</head>
<body>
    <h1>Welcome to My First Web Page</h1>

    <h2>About This Page</h2>
    <p>This page is part of my HTML & CSS course. It uses a title and several headings.</p>

    <h3>What I am learning</h3>
    <p>HTML structure, headings, paragraphs and more.</p>

    <h4>Next steps</h4>
    <p>Links, images, forms and CSS.</p>

    <h5>Heading level 5</h5>
    <h6>Heading level 6</h6>
</body>
</html>

Tags explanation:

1.<!DOCTYPE html> — Browser ko batata hai ki document HTML5 hai.
2.<html> — HTML document ki shuruaat karta hai.
3.<head> — Page ki information rakhta hai.
4.<title> — Browser tab mein page ka naam dikhata hai.
5.<body> — Page par dikhne wala content rakhta hai.
6.<h1> se <h6> — Alag-alag levels ki headings banate hain.
7.<p> — Paragraph likhne ke liye use hota hai.
8.</body> aur </html> — HTML document ko close karte hain.
