GitHub Repository Link?

Aim: To create a GitHub repository and upload HTML and CSS files.
Introduction:
GitHub is an online platform used to store and share code. A repository is used to keep project files in one place.

Procedure:
Step 1: Create a Repository
Open GitHub.com and log in to your account.
1.Click on New Repository.
2.Enter the repository name html-css-assignments.
3.Create the repository without a README file.
Step 2: Upload Project Files
Open the terminal in your project folder.
Connect your project to GitHub using the following command:
git remote add origin https://github.com/your-username/html-css-assignments.git
Rename the branch to main:
git branch -M main
Upload the files to GitHub:
git push -u origin main
Replace your-username with your GitHub username.
Step 3: Verify the Repository
Open your GitHub repository and refresh the page. Check that all project files are uploaded successfully.
Step 4: Publish the Website (Optional)
1.Open repository Settings.
2.Click on Pages.
3.Select the main branch and / (root) folder.
4.Click Save to publish the website.

Result:
The GitHub repository was created successfully, and the HTML and CSS project files were uploaded. The website can also be published using GitHub Pages.
