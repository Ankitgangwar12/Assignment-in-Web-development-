Terminal Navigation Practice Sheet?

terminal command to creating folders, managing file and navigation dicractories.
1.Basic terminal terms:
1.pwd
It shows the current working directory.
2. ls
It displays the files and folders in the current directory.
3. mkdir practice
It creates a new folder named practice
4. cd practice
It moves into the practice folder.
5. touch index.html
It creates an empty HTML file.
6. cd ..
It moves back to the parent directory.
7. cp index.html backup.html
It creates a copy of the index.html file.
8. mv backup.html old.html
It renames backup.html to old.html.
9. cat index.html
It displays the contents of the file.
10. code .
It opens the current folder in Visual Studio Code.
