Set proof(Vs code,node.js,Live server)?

introduction:
The purpose of this assignment is to verify that the tools required for web development are installed and working correctly on our computer.

Step1:check visual studio code
• Open VS Code.
• Click on the help menu.
• Select about to check the version of Vs code.
- Vs code is a code editor to used to write and manage HTML,CSS, JavaScript and other programming language.

Step2:Check Node.js and npm
Open the terminal in VS Code and run these commands:
node-v= displays the installed Node.js version.
npm-v= displays the installed npm version.

Node.js allows JavaScript to run outside a web browser, while npm helps manage JavaScript packages.

Step3:Live server
• Open the Extensions panel in VS Code.
• Search for Live Server by Ritwick Dey.
• Click Install.
-Live Server runs an HTML webpage on a local development server and automatically refreshes the page when changes are saved.

Step4:Run an HTML Page
• Create an HTML file named .
index.html.
• Write some basic HTML code.
• Save the file.
• Click Go Live in VS Code.
• The webpage will open in your default browser.

Step5:Take Screenshot 
• VS Code version.
• Node.js and npm versions in the terminal.
• Installed Live Server extension.
• The webpage running in the browser.
- Save the screenshots in a folder named screenshots using the filename setup-proof.png where appropriate.
