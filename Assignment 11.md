Explanation:
• <!DOCTYPE html> & <html lang="en">: Ye browser ko batata hai ki yeh ek modern HTML5 document hai aur iski bhasha English hai.  
• <head> aur <meta> tags: Is section mein page ki metadata jaise character encoding (UTF-8), screen scaling ke liye viewport, aur search engines ke liye description di gayi hai.  
• <header> aur <nav>: Header ke andar ek main heading (<h1>) hai aur <nav> tag ke zariye website ke alag-alag sections par jaane ke liye ek list (<ul> aur <li>) banayi gayi hai.  
• <main> aur <section> tags: Page ke main content ko alag-alag sections (jaise Introduction, Works, Expertise, aur Reach Me) mein baanta gaya hai taaki code structured lage.  
• Links (<a>): Inka use karke internal navigation (page ke andar hi jump karna), external links kholna (jaise GitHub), aur email bhejne ke liye (mailto:) features add kiye gaye hain.  
• <footer>: Ye page ka sabse nichla hissa hota hai, jismein upar jaane ke liye "Scroll to Top" ka link aur doosre pages ke links diye gaye hain.
