Git and GitHub practice ?
- Git to track change and github to store the projects.
Git commands:
1. Git Version
git --version

It checks whether Git is installed.
2. Initialize Git
git init

It creates a Git repository in the current folder.
3. Check Status
git status

It shows the current status of files.
4. Add Files
git add .

It prepares files for saving.
5. Commit Changes
git commit -m "First commit"

It saves the changes with a message.
6. Check History
git log --oneline

It displays the history of commits.
4. GitHub
GitHub is an online platform used to store, manage, and share projects. We can upload our local Git repository to GitHub.
